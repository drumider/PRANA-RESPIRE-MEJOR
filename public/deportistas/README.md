# Carpeta para Foto de "Deportistas"

Para reemplazar la imagen de la sección **Deportistas**:

1. Suba o arrastre su imagen a esta carpeta (`/public/deportistas/`).
2. Nómbrela **`imagen-deportistas.jpg`** (o `imagen-deportistas.png`) para reemplazar la foto actual automáticamente.
3. Si le asigna otro nombre a su archivo, reemplace el nombre del archivo en la aplicación.
