# Carpeta de Fotos del Equipo Médico / Team Photos Folder

Para reemplazar la foto del **Dr. Randall Guadamuz** que se muestra en la sección "Sobre Nosotros":

1. Coloque su archivo de imagen en esta carpeta (`/public/equipo/`).
2. Nómbrelo exactamente: **`dr-randall-guadamuz.jpg`** (o `dr-randall-guadamuz.png`).
3. La aplicación cargará automáticamente su nueva foto sin necesidad de modificar el código.
