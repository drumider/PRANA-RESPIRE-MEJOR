========================================================================
CARPETA PARA TUS IMÁGENES DEL HERO (PRANA NEUMOLOGÍA)
========================================================================

Instrucciones para cambiar o agregar imágenes:

1. Coloca aquí tus imágenes guardándolas con estos nombres:
   - imagen1.png
   - imagen2.png
   (o el formato que desees .png, .webp, .jpg)

2. Si agregas más imágenes o usas otros nombres, actualiza la lista en el archivo:
   /src/data/heroImages.ts

3. La aplicación automáticamente cambiará entre las imágenes con un suave
   efecto de transición cada 4 segundos.
========================================================================
