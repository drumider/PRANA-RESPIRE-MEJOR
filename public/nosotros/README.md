# Carpeta para Foto de "Acerca de Nosotros" / About Us Image Folder

Para reemplazar la imagen superior de la sección **Acerca de Nosotros / About Us**:

1. Suba o arrastre su imagen a esta carpeta (`/public/nosotros/`).
2. Puede nombrar su archivo **`imagen-nosotros.jpg`** (o **`imagen-nosotros.png`**) para reemplazar la foto actual automáticamente.
3. Si le asigna otro nombre (ej. `mi-foto.jpg`), solo actualice el nombre del archivo en la aplicación.
