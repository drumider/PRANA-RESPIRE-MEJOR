# Carpeta para Foto de la Psicóloga

Guarde aquí la fotografía de la psicóloga especialista en Neurofeedback.

- **Ruta de imagen predeterminada:** `/public/psicologia/psicologa.jpg` (o `/public/neurofeedback/psicologa/psicologa.jpg`)
- **Formatos soportados:** JPG, PNG, WEBP
- **Recomendación:** Usar una imagen cuadrada (proporción 1:1) o vertical.
