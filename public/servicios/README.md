# Carpeta para Foto de "Exámenes Médicos / Servicios"

Para reemplazar esta imagen de la sección **Exámenes Médicos / Servicios**:

1. Suba o arrastre su imagen a esta carpeta (`/public/servicios/`).
2. Nómbrela **`imagen-examenes.jpg`** (o `imagen-examenes.png`) para reemplazar la foto actual automáticamente.
3. Si le asigna otro nombre a su archivo, reemplace la ruta correspondiente en el código de la aplicación.
