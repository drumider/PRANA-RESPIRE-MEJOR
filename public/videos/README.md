# Carpeta para Videos Educativos

Para agregar o reemplazar los videos de **Respimat** y **Airflusal**:

1. Suba sus archivos de video (.mp4) a esta carpeta (`/public/videos/`).
2. Nómbrelos:
   - **`respimat.mp4`** (para el Inhalador Respimat)
   - **`airflusal.mp4`** (para el Inhalador Airflusal)
3. La página detectará los videos automáticamente una vez subidos.
